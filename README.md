# Эмулятор командной строки (Shell Emulator)

Практическая работа №1 по дисциплине «Конфигурационное управление».
Преподаватель: Советов П. Н.

## Описание проекта
Данный проект представляет собой эмулятор командной оболочки ОС UNIX-подобных систем. Эмулятор работает с виртуальной файловой системой (VFS), загружаемой в память, и поддерживает выполнение основных консольных команд.

## Настройки и параметры запуска
Эмулятор принимает параметры командной строки:
* `--vfs` — путь к архиву/файлу виртуальной файловой системы.
* `--script` — путь к стартовому скрипту с командами.

## Поддерживаемые команды
* `ls` — вывод содержимого текущего каталога VFS.
* `cd` — смена текущего каталога VFS.
* `exit` — завершение работы эмулятора.

## Сборка и запуск
Запуск приложения осуществляется через командную строку или скрипт `run.bat`:

```bash
run.bat
